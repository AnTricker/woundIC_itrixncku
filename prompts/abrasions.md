[CATEGORY]
Abrasions

[POSITIVE CUES]
- Superficial epidermal loss from friction or scraping.
- Irregular or streaked friction pattern.
- Pinpoint bleeding, petechiae, raw erythematous surface, or serous weeping.
- Embedded dirt, grit, or foreign material only if directly visible.

[NEGATIVE REPORTING]
- If no epidermal scraping is visible, write "abrasion pattern not observed".
- If no debris is visible, report foreign material/debris as "not observed".
- If no fluid or pinpoint bleeding is visible, report it as "not observed".

[CONFUSABLE CATEGORIES]
- Bruise: intact epidermis with discoloration but no scraped surface.
- Cut/incision: clean linear break with sharper edges.
- Laceration: torn jagged margins, possible tissue flap or bridging.

[FORBIDDEN INFERENCE]
- Do not infer contamination, infection, or healing stage unless visible signs support it.
- Do not estimate dimensions without a visible measurement tool.
